# Directorist Template Overrides

To override any Directorist template file:
1. Locate the original file in `wp-content/plugins/directorist/templates/` (e.g. `single/header.php`, `archive/grid-view.php`).
2. Copy it into this directory preserving the folder path (e.g. `wp-content/themes/onelisting-child/directorist/single/header.php`).
3. Modify the copied file as desired. Your changes will persist across Directorist plugin updates.
